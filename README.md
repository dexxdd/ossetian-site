# 🛡️ Личный VPS-сервер: VLESS-XHTTP + 3X-UI + Сайт «История Осетии»

Скрипт автоматического развертывания персонального защищенного узла связи **VLESS-XHTTP (SplitHTTP)** на порту `443` с маскировкой под полноценный исторический сайт об **Алании и Осетии** на порту `80`.

---

## ⚡ Быстрая установка в 1 команду

Подключитесь к вашему чистому VPS-серверу (Ubuntu 22.04 / 24.04 или Debian 11 / 12) по SSH и вставьте команду:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/dexxdd/ossetian-site/main/install.sh)
```

> **Альтернативный вариант** (если хотите сохранить файл скрипта на сервере):
> ```bash
> curl -sSL https://raw.githubusercontent.com/dexxdd/ossetian-site/main/install.sh -o install.sh && sudo bash install.sh
> ```

---

## 📋 Что подготовить перед запуском (DNS)

1. **A-запись домена:**
   * В панели регистратора домена (или хостинга) создайте запись:
     * **Тип:** `A`
     * **Имя (Host):** `@` (или имя поддомена, например `vpn`)
     * **Значение:** IP-адрес вашего VPS
     * **TTL:** `300` (5 минут) или `Auto`
2. **Если домен подключен к Cloudflare:**
   * Оранжевое облако (**Proxy status**) должно быть **ОБЯЗАТЕЛЬНО ВЫКЛЮЧЕНО**!
   * Значок должен быть серым (**DNS only**), иначе Let's Encrypt не сможет выдать сертификат.

## 🖥️ Что вводить в процессе установки (Пошагово)

Скрипт выполняет всё автоматически, от вас потребуется ответить всего на 2 вопроса:

### 1. Ввод домена
```text
Введите ваш домен (например, your-domain.org):
```
👉 **Что делать:** Впишите ваш домен (например, `your-domain.org`) и нажмите **[Enter]**.

---

### 2. Настройка белого списка панели 3X-UI (UFW)
Скрипт сам определит ваш текущий IP-адрес подключения и покажет меню:
```text
 [+] Ваш текущий IP-адрес подключения (SSH): 203.0.113.xxx

 Формат ввода:
 • Разрешить вход только с вашего текущего IP:
   👉 Просто нажмите [Enter]

 • Указать один или несколько своих IP/подсетей через запятую:
   👉 Пример: 203.0.113.195, 198.51.100.0/24

 • Открыть вход в панель со всех IP мира (без ограничений):
   👉 Напишите: all
```
👉 **Что делать:**
* **Рекомендуется:** Просто нажмите **[Enter]** — панель будет доступна только с вашего текущего IP (максимальная безопасность).
* Если у вас динамический IP или вы хотите заходить отовсюду — напишите `all` и нажмите **[Enter]**.

## ⚙️ Что скрипт делает сам «под капотом»

1. **Обновляет систему** и устанавливает необходимые утилиты (`nginx`, `certbot`, `ufw`, `3x-ui`, `qrencode`, `sqlite3` и др.).
2. **Выпускает бесплатный доверенный SSL-сертификат Let's Encrypt** для вашего домена.
3. **Разворачивает сайт об истории Осетии** (HTML5, стили, галерея изображений) в `/var/www/html` и запускает Nginx на порту `80`.
4. **Устанавливает панель 3X-UI** на случайном защищенном порту с уникальным секретным веб-путем.
5. **Генерирует подключение VLESS-XHTTP** на порту `443`:
   * Шифрование: `TLS` (Let's Encrypt)
   * Маскировка отпечатков (uTLS): `Edge`
   * Режим транспорта: `xhttp` (SplitHTTP)
   * Хост и SNI: ваш домен
   * Путь: `/api/`
   * Случайный padding: `100-1000` (защита от сигнатурного анализа трафика)
6. **Настраивает фаервол UFW:**
   * Открыты порты: `22` (SSH), `80` (Сайт), `443` (VLESS XHTTP).
   * Порт панели управления открыт только для доверенных IP (белый список).
7. **Выводит в консоль готовую ссылку подключения и QR-код для смартфона.**

## 📱 После установки: как подключиться

В конце работы скрипт выведет:
1. **Ссылка на сайт-заглушку:** `http://ваш-домен.org` (можно открыть в любом браузере).
2. **Вход в админ-панель 3X-UI:** адрес со случайным секретным путем, логин `admin` и сгенерированный пароль.
3. **VLESS-ссылка:** строка вида `vless://...#VLESS-XHTTP` — скопируйте её в ваш клиент:
   * **Windows:** v2rayN, Nekoray, Hiddify
   * **Android:** v2rayNG, Happ, Hiddify
   * **iOS:** FoXray, Streisand, Shadowrocket, V2Box, Happ
4. **QR-код прямо в терминале:** можно просто отсканировать камерой приложения на телефоне.

## 🛠️ Полезные команды для обслуживания сервера

* **Перезапуск панели 3X-UI:**
  ```bash
  systemctl restart x-ui
  ```
* **Проверка статуса веб-сервера Nginx:**
  ```bash
  systemctl status nginx
  ```
* **Просмотр правил фаервола:**
  ```bash
  ufw status verbose
  ```
* **Добавить новый IP в белый список панели:**
  ```bash
  ufw allow from НОВЫЙ_IP to any port ВАШ_ПОРТ_ПАНЕЛИ proto tcp
  ```
